# Projeto Calculadora

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma calculadora utilizando a linguagem Python, com o objetivo de praticar conceitos fundamentais de programação e lógica computacional.

## Tecnologias utilizadas

- Python 3
- Shell Script (Bash)
- Git e GitHub

## Estrutura do projeto

- `calculadora.py`: arquivo responsável pela implementação da calculadora em Python.
- `calculadora.sh`: script responsável pela execução do programa.
- `README.md`: documentação do projeto.

## Como executar o projeto

### 1. Pré-requisitos

- Ter o Python 3 instalado.
- Ter acesso a um terminal.

### 2. Executar pelo Python

No terminal, acesse a pasta do projeto e execute:

```bash
python3 calculadora.py
```

### 3. Executar pelo Shell Script

Primeiro, dê permissão de execução ao arquivo:

```bash
chmod +x calculadora.sh
```

Depois, execute:

```bash
./calculadora.sh
```

## Objetivo de aprendizagem

Praticar lógica de programação, desenvolvimento com Python, execução de scripts Shell e organização de projetos utilizando GitHub.
